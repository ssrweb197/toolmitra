How to use this tool

  1. Enter the full URL of the public page you want to inspect.
  2. Click Run free check.
  3. Review the detected title and meta tags, including description, robots, Open Graph, Twitter card and viewport values.
  4. Compare the values with the page's actual purpose and correct any missing or outdated tags in your website CMS or source code.
  5. Re-run the checker after publishing your changes.

Example

For example, enter https://example.com/about to inspect the metadata returned for that specific page. Use a unique, accurate title and description that describe the page rather than repeating keywords.

Frequently Asked Questions

Does this tool generate meta tags?

This page checks and previews tags found in the submitted page's HTML. It does not automatically edit your website source code.

Will Google always use my meta description?

No. Search engines may generate a different search snippet depending on the query and page content.

Why are Open Graph tags useful?

They provide information that social platforms may use when creating link previews. Platforms can cache or choose different preview content.

What is a canonical tag?

A canonical link element can indicate a preferred URL for similar or duplicate pages. It should point to the correct canonical version.

Why are tags missing when I can see them in my browser?

Some sites add metadata with JavaScript after the initial HTML response. This checker inspects the HTML response it can retrieve, so dynamically added tags may not appear.
