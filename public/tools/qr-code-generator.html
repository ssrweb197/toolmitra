What information can a QR code store?

A QR code can encode a web address, a short text message, Wi-Fi connection details, an email action, a telephone number or a vCard contact. When scanned, the phone's camera or QR reader interprets the encoded information. The action offered by the phone can vary by device and operating system.

Frequently asked questions

Are the QR codes free?

Yes. This generator is free to use and does not require an account. The generated QR code is a static code containing the information you provide.

Do QR codes expire?

A static QR code does not have an expiry date built into it. A QR code containing a website link will continue to work as long as the destination remains available. If the destination changes or disappears, the QR code itself does not update.

Can I use the QR code for business?

You can use the downloaded QR image on menus, flyers, packaging, business cards and other materials. Always test it at the printed size and make sure the encoded destination is correct.
