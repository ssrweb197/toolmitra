How to use this tool

  1. Enter a public website URL in the input field.
  2. Click Run free check to request the health scan.
  3. Review availability, response-time, security-header, robots.txt, sitemap, favicon, viewport and language checks shown in the report.
  4. Read the recommendations and verify important server or security changes with your hosting provider.
  5. After making changes, run the check again to compare the returned signals.

Frequently Asked Questions

Is response time the same as page speed?

No. It is a basic response measurement from the scan. It does not measure all Core Web Vitals, rendering performance or real-user experience.

Why are some security headers missing?

Your server, CDN or hosting configuration may not send those headers. Whether each header is appropriate depends on the website and its setup.

Why is my sitemap not detected?

The sitemap may be located at a different URL, be blocked, return an error, or use a format the current check does not recognise.

Does this tool test my website for malware?

No. It checks selected public availability and configuration signals; it is not a malware scanner, penetration test or security audit.

Can a website be healthy with warnings?

Yes. Warnings are prompts for manual review, not proof that a site is broken. Review each finding in context.

ToolMitra reports are automated technical indicators based on publicly accessible responses. Results can be incomplete or affected by website configuration, network conditions or bot restrictions. Review important findings manually.
