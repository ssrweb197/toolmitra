How to use the JSON formatter

  1. Paste or type your JSON into the editor.
  2. Choose 2 spaces, 4 spaces or tabs for indentation.
  3. Select Format / Beautify to make it readable, Validate to check syntax, or Minify to remove unnecessary whitespace.
  4. Copy the result or download it as a .json file.

What is JSON?

JSON (JavaScript Object Notation) is a text format commonly used to exchange structured data between applications and APIs. It supports objects, arrays, strings, numbers, booleans and null values. JSON requires double quotes around property names and strings, and it does not allow comments or trailing commas.

Frequently asked questions

Does this tool send my JSON to a server?

No. Validation and formatting use your browser's built-in JSON parser. Your input stays in the current browser page.

Why does my JSON show a syntax error?

Common causes include missing commas or quotation marks, single quotes, trailing commas, comments and unmatched braces or brackets. The error message may include a position to help you locate the issue.

Does minifying JSON change its data?

Minifying removes formatting whitespace while keeping the parsed JSON data structure and values. It does not rename fields or change values.
