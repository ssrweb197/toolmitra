Open Graph Preview Guide

Preview the title, description and image that may appear when a page is shared on social platforms.

Open Open Graph Preview →

What this tool does

Open Graph metadata helps social platforms understand which title, description and image to use for a shared link. Platforms may cache previews or apply their own display rules.

How to use it

Enter the page URL, inspect the preview, compare it with the page's intended message, then update the page metadata and image if needed.

Practical tips and best practices

Use a relevant high-quality image, readable title and concise description. Ensure the image URL is publicly accessible and the metadata reflects the page itself.

Important limitations

A preview tool cannot guarantee an identical display on every platform. Social networks may cache old metadata; use their available debugging or refresh tools when appropriate.

Frequently asked questions

Why is the old image still showing?

The platform may have cached an earlier preview.

Does Open Graph affect Google rankings directly?

It is primarily for social sharing presentation, not a direct ranking switch.

What image should I use?

Use a clear, relevant image that you own or have permission to use.

Are og:title and the HTML title the same?

They can be similar, but serve different display contexts.

Why is my preview blank?

Check that metadata and image URLs are public and return successfully.
