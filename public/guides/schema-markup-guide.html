What this tool does

Structured data is machine-readable information that describes entities and page content. Valid markup can help search engines interpret a page, but rich-result eligibility depends on search engine rules and the page itself.

How to use it

Choose the relevant schema type, enter accurate details, generate the JSON-LD, review every field, add it to the matching page and test it with an appropriate validator.

Practical tips and best practices

Only describe content visible to visitors. Keep names, dates, prices, ratings and other details accurate and up to date. Do not add fake reviews or misleading fields.

Important limitations

Generated markup is a starting point. Validate syntax and eligibility, and check current search engine documentation before publishing.

Frequently asked questions

Does schema guarantee rich results?

No. Search engines decide whether eligible results are shown.

Can I add markup for content not visible on my page?

Do not use structured data to misrepresent the page.

Where does JSON-LD go?

It is commonly added in a script element in the page head or body.

Should every page use the same schema?

No. Choose types that accurately match each page.

How do I test it?

Use a structured-data or rich-results testing tool and fix reported errors.
