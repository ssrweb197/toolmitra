What this tool does

JSON is a text format used to exchange structured data. A formatter adds indentation for readability, while a validator checks whether the text follows JSON syntax.

How to use it

Paste JSON into the editor, choose format or validate, read any error message, correct the syntax and try again. Use minify only when a compact representation is needed.

Practical tips and best practices

Use double quotes around strings and property names, commas between items, and no trailing commas. JSON supports objects, arrays, strings, numbers, booleans and null.

Important limitations

Do not paste passwords, API keys, private customer records or other secrets into online tools. Even when processing is local, avoid sharing sensitive data unnecessarily.

Frequently asked questions

Why is my JSON invalid?

Common causes include single quotes, trailing commas, missing commas or unmatched brackets.

Does JSON allow comments?

Standard JSON does not allow comments.

Can JSON contain undefined?

No. Use null where an explicit empty value is appropriate.

What is minified JSON?

JSON with unnecessary whitespace removed.

Is formatting the same as validation?

Formatting changes presentation; validation checks syntax.
